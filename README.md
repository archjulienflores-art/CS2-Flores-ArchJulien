# Electricity Bill Calculator

## Description
This program gets the total bill based on the readings.

## Version 1 - Original code without input validation
- Input: Accepts a customer's name, current, and previous reading
- Process: Gets the consumption (current-previous) and multiply it by the rate (12.90)
- Output: Total Bill
- Does not include input validation.

## Version 2 - Original code with input validation
- Input: Accepts a customer's name, current, and previous reading
- After each input, the program validates each input with input validations.
- Process: Gets the consumption (current-previous) and multiply it by the rate (12.90)
- Output: Total Bill
